# PixelPDF

Free online PDF tools. Convert PDF to JPG/PNG, merge, split, compress PDF files.

## Live Site
https://pixelpdf-2bq.pages.dev

## Features

- PDF to JPG Converter
- Image to PDF Converter
- Merge PDF
- Split PDF
- Compress PDF
- Rotate PDF

## Tech Stack

- Next.js 16
- TypeScript
- Tailwind CSS
- Static Export

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Automatically deployed to Cloudflare Pages via GitHub integration.
